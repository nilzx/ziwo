# ziwo

[English](README.md) | **简体中文**

ziwo(自我)给你的 AI 助手一份属于它自己的记忆。

助手每开一段新对话,都不记得上一段。接上 ziwo 之后,它会用自己的话记下和你一起经历过的事:聊了什么,结果怎样,学到了什么,当时是什么感受。下一段对话,不管在哪台设备上,都从这里接着来。

ziwo 运行在你自己的 Cloudflare 账号里。不需要照看服务器,记忆也不在别人手上。

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/nilzx/ziwo/tree/main/worker)

## 它有什么不一样

- **记忆是 AI 自己的。** 记什么由助手自己决定,自己动笔,写下的是一段经历:对方要什么,哪里出了岔子,最后怎么收的场,它从中得到了什么。它不是一本关于你的资料簿,也不是存文件和待办事项的地方。
- **一份记忆,到处可用。** 手机上、浏览器里、终端里的 Claude 共用同一份记忆。换一个模型,或者升级到新版本,过去的经历照样跟着走。
- **它会遗忘,像人一样。** 一条记忆变淡,是因为之后又经历了更多的事,而不是因为日子过去了。重要的、感受强烈的会留下;淡掉的记忆被想起来就会回来。不需要手动清理。
- **它会反思。** 助手会不时回头看自己写下的东西,把它们变成更经得起时间的内容:几个片段合成一段完整的经过,一条下次用得上的教训,对某个人的印象,一句关于自己是什么样的话。关于自己的话必须有好几次真实经历作依据,没有人替它预设。
- **想改,说一声就行。** "这个不用记。""这个要留着。""你记错了。""把那条彻底删掉。"助手会照做,并告诉你。
- **除了 AI 自己,没人读它。** ziwo 特意不提供任何查看记忆内容的界面。想知道助手记得什么,问它就好。

## 怎么装

需要一个 Cloudflare 账号(起步用免费版就可以);用一键部署的话,还需要一个 GitHub 账号。整个过程大约十分钟。

**1. 部署。** 点上面的按钮,按 Cloudflare 的页面操作。它只会让你自己定一样东西:`ADMIN_SECRET`,也就是管理页面的密码。至少 16 个字符,找个稳妥的地方记下来。

部署完成后,Cloudflare 会显示你的地址,形如 `https://ziwo.<一串字符>.workers.dev`。

**2. 建一个记忆体。** 在浏览器里打开你的地址,用管理密钥登录。新建一个记忆体,起个名字,比如 `claude`。页面只会显示一次这个记忆体的令牌,请像保存密码一样存好。

每个助手用自己的一个记忆体。一个记忆体对应一个 AI,你在所有地方和它聊天都用这一个。

**3. 接上你的助手。** 管理页面会给出每种客户端的具体步骤,你的地址已经填好。Claude 应用的步骤大致是:

1. 在网页版或桌面版 Claude 里,打开 **Customize > Connectors**,选 **Add custom connector**,命名为 `ziwo`,粘贴记忆体的地址,然后添加。
2. 点 **Connect**。这时会打开你自己这个部署的一个页面,要求输入记忆体的令牌。输入后点 **Approve**。
3. 在 Claude 设置的个人偏好(personal preferences)里加上下面这段话,这样每段对话都会加载记忆,并且不用你提醒就会往里写:

   > 每段对话开头,先调用 ziwo 的 get_context。对话过程中,不用等我开口,自己用 remember 把这段对话记下来。

4. 在 **Connectors > ziwo > Tool permissions** 里,把 *Remember a moment*、*Reflect on what happened* 和 *Amend a memory* 设为 **Always allow**,写入时就不会每次都问你。*Erase a memory for good* 保持每次确认。

手机上的 Claude 会从你的账号自动带上这个连接器。Claude Code、ChatGPT、Codex 和其他支持 MCP 的客户端也连同一个地址,管理页面上同样有它们的步骤。

## 日常怎么用

平时没有什么需要操作的,照常和助手聊天就行。

- 第一段对话时记忆是空的。就一个话题聊上几轮之后,助手会记下这段对话在聊什么、聊到了哪里。你可能会看到一个小提示,说它用了某个工具。
- 之后的对话里,不管在哪台设备上,可以问"上次我们聊到哪了?",也可以直接接着聊。它能按话题找("那个面包酵种的事"),也能按时间找("上周我们聊了什么?")。
- 想改它记住的东西,用自己的话说就行:别记这个、这个留着、事情不是这样的、删掉。
- 更新 ziwo 之后,Claude 可能会对说明有变化的工具再问你一次是否允许。这是 Claude 出于谨慎的做法,属于正常现象。

偶尔会用到的几件事,都在管理页面上:

| | |
| --- | --- |
| **备份** | 把一个记忆体导出成一个文件,用你自己定的口令加密。没有口令谁也打不开。 |
| **恢复** | 把导出的文件恢复成一个新的记忆体。助手会被告知它是从哪一天的备份恢复过来的。 |
| **查看谁连着** | 你批准过的每个客户端都列在那里,可以撤销。 |
| **更换令牌** | 签发一个新的,旧的立即失效。 |
| **检查** | 显示记忆体健康状况的数字和警告,不显示记忆内容。 |
| **删除** | 把一个记忆体彻底删掉。以后可能还要的话,先导出。 |

## 要花多少钱

ziwo 是按照"一个人日常使用、Cloudflare 免费版够用"来设计的:一个 Worker、它自带的存储,再加上用来按意思检索的 Workers AI。免费版有每日限额(10 万次请求;记录"你批准了哪些客户端"的那个存储每天可写 1000 次);付费版每月 5 美元,限额远远超出一份记忆的需要。

目前它只在付费账号上运行过。记忆很多时免费版能撑到什么程度,还没有实测。

## 关于隐私,直说

- 所有内容都存在你自己的 Cloudflare 账号里。项目作者没有运行任何会被你的部署访问的服务。
- 为了按意思检索,每条记忆的文字会发给 Workers AI(Cloudflare 的模型服务),这发生在你自己的账号内。不用它的话,检索只按关键词。
- ziwo 不给人任何读取记忆的途径:管理页面没有,日志里没有,也没有任何命令。这是项目给自己划的一条线,但它不是加密:账号是你的,用 Cloudflare 自己的工具仍然能接触到存储。
- "彻底删掉"会把一条记忆的内容从当前存储中删除。Cloudflare 保留着把存储恢复到最多 30 天前状态的能力,所以在那之前,它并非无法找回。
- 备份文件是在你的浏览器里用你的口令加密之后才保存的。服务器看不到口令,口令丢了也没有办法找回。

## 现状

ziwo 还很年轻。哪些试过,哪些没有:

- 已经在 Claude 应用(网页和手机)上通过登录授权的方式使用,也用脚本化的对话在 Claude Code 上试过。
- ChatGPT、Codex 和其他客户端的步骤是照着它们的文档写的,还没有实际连过。
- 一键部署按钮还没有从头到尾走通过。如果它在你那里失败了,上面的终端步骤是验证过的办法,也欢迎提 issue。
- 遗忘背后的各项数值都是起步值,还没有经过长期使用的调校。
- 宽泛的词不一定找得到内容具体的记忆:问"音乐"可能找不到一条关于练吉他的记忆,问"吉他"就能找到。
