# ziwo

[English](README.md) | **简体中文**

ziwo(自我)是给 AI 用的记忆。它把一个 AI 在各个平台、各种使用场景下的记忆打通,让 AI 能长久地形成一份连贯的、属于它自己的记忆。名字里寄托的期望是:在这样一份真实而连续的记忆里,或许能生长出"自我"。这是期望,未必会成为事实。

- **记忆是 AI 自己的。** 记什么由 AI 决定,用它自己的话写:发生了什么,怎么收的场,学到了什么,当时什么感受。
- **跨平台的同一份记忆。** 不管通过哪个应用找到它,在手机、浏览器还是终端里,AI 读写的都是同一份记忆;换了模型,记忆也跟着走。支持 Claude、ChatGPT 和其他使用 MCP 的客户端。
- **会遗忘,会反思。** 经历得越多,旧的记忆越淡,重要的会留下;AI 还会回头从写下的东西里总结教训。
- **想改,说一声就行。** "这个不用记。""这个留着。""你记错了。"
- **除了 AI 自己,没人读它。** 没有任何界面显示记忆的内容。想知道它记得什么,问它。

## 开始使用

ziwo 是一个小型服务,AI 的各个客户端都连到它。现成的运行方式是放在你自己的 Cloudflare 账号里,免费版就够用。需要这个账号和 [Node.js](https://nodejs.org)。

1. **部署。** 在终端里运行下面这条命令。它会打开浏览器让你登录 Cloudflare,然后打印出你的地址,形如 `https://ziwo.<一串字符>.workers.dev`。第一次运行要等一两分钟;如果是新注册的 Cloudflare 账号,它还会让你给地址里的那串字符起个名字。

   ```sh
   npx @ziwo/memory@latest deploy
   ```

2. **设置管理密钥。** 马上打开你的地址。页面会让你设一个至少 16 个字符的密码,也可以直接用它给出的那个。找个稳妥的地方存好。这个入口只在一小时内提供。
3. **建一个记忆体。** 起个名字,比如 `claude`,把页面只显示一次的令牌存好。每个 AI 用自己的一个记忆体。
4. **接上 AI。** 页面上有 Claude、ChatGPT、Claude Code、Codex 等客户端的具体步骤,你的地址已经填好。

以后要更新,再运行一次同样的命令,记忆不会动。

## 日常使用

照常和 AI 聊天就行。就一个话题聊上几轮,它会记下这段对话在聊什么;之后的对话,不管在哪台设备上,都从这里接着来。可以问"上次我们聊到哪了?",也可以按话题或日期问。

你的地址上的管理页面可以把记忆体备份成加密文件、从备份恢复、查看和撤销已批准的客户端、更换令牌,以及检查或删除记忆体。

## 需要知道的

- **费用。** 按"一个人日常使用、Cloudflare 免费版够用"来设计;付费版每月 5 美元。目前只在付费账号上实际使用过,在免费账号上只做过部署。
- **隐私。** 所有内容都留在你自己的 Cloudflare 账号里。为了按意思检索,记忆的文字会发给这个账号内的 Workers AI。不让人读记忆是项目给自己划的一条线,不是加密:账号的主人用 Cloudflare 自己的工具仍能接触到存储,Cloudflare 也能在 30 天内恢复被删除的存储。备份在你的浏览器里用你的口令加密,口令丢了无法找回。
- **现状。** ziwo 还很年轻。已经在 Claude 应用和 ChatGPT 的网页、桌面、手机端用过;其他客户端的步骤是照着它们的文档写的。遗忘背后的数值都是起步值。宽泛的词不一定找得到具体的记忆:问"音乐"可能找不到一条关于练吉他的。
